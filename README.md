# Projeto-Agrinho

Projeto desenvolvido para o **Concurso Agrinho** durante o curso técnico em 2024. O objetivo do projeto foi criar um site informativo sobre o programa Agrinho, utilizando conceitos básicos de desenvolvimento web.

O projeto foi desenvolvido utilizando **HTML e CSS**, com foco em praticar a criação de páginas, organização de conteúdo, menus de navegação, formulários, imagens e estilização.

### Funcionalidades

* Página inicial com informações sobre o Agrinho;
* Página com informações sobre os parceiros;
* Página de contato com formulário;
* Menu de navegação entre as páginas;
* Utilização de imagens e textos informativos;
* Layout responsivo para diferentes tamanhos de tela;
* Estilização das páginas utilizando CSS.

### Tecnologias utilizadas

* HTML5
* CSS3

### Objetivo

Este projeto foi desenvolvido principalmente para **estudo e aprendizado**, servindo como uma das primeiras experiências práticas com desenvolvimento de páginas web durante o curso técnico.

Foi uma oportunidade para colocar em prática conceitos aprendidos em sala de aula e entender melhor como HTML e CSS trabalham juntos na criação de um site.
